From the repository root: `npm run lesson18`.

The automated tests use local adapters and a small DOM stand-in. The browser shell is an in-memory simulation: no wallet, proof or chain transaction occurs. A hosted copy still gives each browser its own simulation; hosting alone does not connect users to shared state. Keyboard/browser checks are manual. Follow the [deployment guide](../../../docs/deployment.md) before replacing the adapter with real confirmed calls and indexed state.

After comparing, close this answer and explain the rule from memory. Make changes
in the exercise folder, then rerun its checkpoint; running this reference does not
